# Python 编程工具 🐍

> 打中文出代码 · 报错说人话 · 一键装库 —— 全部离线可用、绿色免安装、不代写
>
> 面向中小学生的 Python 入门与应用学习工具（非信奥赛方向）

## ✨ 项目特色

### 1. 双语词汇幽灵提示（打字即提示，Tab 采纳）
- 打「输出」「循环」「随机整数」→ 直接提示 `print`、`for`、`random.randint(最小值, 最大值)`
- 打拼音 `shuchu` → 提示 `print`；打英文首字母 `pri` → 补全 `print(要显示的内容)`
- 打 `.` 后 → 方法候选（带中文说明），如 `names.` → `append(要加的内容)`
- VS Code 式浅灰 ghost：只在打字时出现，Tab 采纳后才成为正文
- **整段代码生成永远不提供**——提示不代写是产品红线

### 2. 熟练度渐退（帮你记住，而不是帮你写）
- 本地统计每个词的使用：采纳 +1 分、自己默写 +2 分
- 生词（0-3 分）→ 完整提示立即出现
- 学习中（4-7 分）→ **延迟 1.9 秒出现**，先给回忆窗口
- 掌握（8 分+）→ 英文通道只给元提示线索（「记得吗？print · 5 个字母」）；中文通道给首字母打码 `p····(要显示的内容)`
- 默写出来会有 🎉 掌握通知（每词一次）

### 3. 提示档位（备考/创作两不误）
- **基础语法档**（默认）：只提示 GESP 等级考试范围——关键字、内置函数、字符串/列表/字典方法、文件读写
- **创新档**：全量含 turtle/random/time/math 等开放库

### 4. 中文报错翻译（一键修复）
- 报错变人话 + 常见原因 + 修改建议
- 「是不是想写 print？」→ 拼写建议一键替换
- 「一键把代码里的中文标点改成英文」→ 初学者最高频错误秒修

### 5. 一键装库（VS Code 扩展式面板）
- 左侧 📦 图标打开库面板：搜索 + 常用库一键安装
- 装完自动验证 `import` 确认可用
- 已安装列表实时刷新

### 6. 终端式控制台
- 输入输出在同一流中（像真终端），光标闪烁等待输入
- `input()` 的提示语直接印在输出流里，块状光标闪烁
- 支持 matplotlib 图表内联显示

### 7. 海龟画布自动弹窗
- 运行 turtle 程序时画布浮窗自动弹出（不占界面）
- 关掉后下次有绘图再自动弹出，画面保留

### 8. 四套全界面主题
- 薄荷绿（默认）/ 纯白（投影）/ 米黄护眼 / 夜空（深色）
- 整个应用界面联动切换，不只有编辑器

## 📦 安装与运行

### 桌面版（推荐）

**绿色免安装版**：从 [Releases](../../releases) 下载 zip，解压后双击 `Python编程工具.exe` 即可。

**无需安装 Python**——内嵌完整运行时（Python 3.12 + Jupyter + matplotlib），用户电脑什么都不用装。

### 从源码构建

```bash
# 前置：Node.js 18+ / Python 3.10+ / Rust
npm install                          # 安装前端依赖
npm run sidecar:setup                # 准备 Python venv
npm run build                        # 构建界面
cd apps/desktop && cargo build --release  # 构建桌面壳
./make-portable.bat                  # 组装绿色发行包（含内嵌 Python）
```
